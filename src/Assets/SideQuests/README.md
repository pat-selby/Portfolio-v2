# Side-quest photos

Drop image files straight into this folder. They appear on the home page
automatically, no code changes needed.

Name each file like this:

    Org - Caption.jpg

The part before the first " - " becomes the small label, the rest becomes the
caption. Examples:

    TMCF - Leadership Institute 2026.jpg
    IOBSE - Annual conference in Houston.jpg
    NSBE - Regional convention with the chapter.jpg
    CodePath - Cybersecurity cohort demo day.jpg

Use .jpg, .jpeg, .png or .webp. Landscape or portrait both work.
Aim for roughly 1200px on the long edge so the page stays fast.
