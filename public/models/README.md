# avatar.glb

RobotExpressive by Tomás Laulhé (Quaternius), CC0 1.0, with facial-expression
morph targets added by Don McCurdy. Copied from the three.js examples (r160):
https://github.com/mrdoob/three.js/tree/r160/examples/models/gltf/RobotExpressive

To use a different avatar, replace this file with any rigged GLB that has
"Idle" and "Wave" animation clips (optionally "ThumbsUp" and "Yes").
